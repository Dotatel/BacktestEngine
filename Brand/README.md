# Dotatel brand

`brand-tokens.json` is copied unchanged from `../Levin/Brand/brand-tokens.json`.
It contains the company palette, typography, slogan, and logo sizing guidance.

| Token | Color | Role |
| --- | --- | --- |
| phosphor | #C7FF1A | Brand accent |
| ink | #080D0A | Dark base |
| forest | #102417 | Dark surface |
| paper | #F4F6EE | Light base |
| steel | #5E6961 | Secondary neutral |
| mist | #DDE2D8 | Light neutral |
| grid | #294432 | Dark border/grid |
| positive | #22C55E | Positive status |
| warning | #F6B73C | Warning status |
| negative | #F05A67 | Negative status |

Typography: Manrope (primary), Source Serif 4 (editorial), Arial/sans-serif fallback.

The portable design entry point is [DESIGN.md](../DESIGN.md). Fonts and icon
licenses are bundled with the design package. The private design skill and book
remain local and are not required to read or implement the shared design context.
