# Build workspace reuse decisions

Research verified on 24 October 2026 through official sources and package registry metadata. Use `.agents/skills/reuse-first/SKILL.md` for additional gaps; these choices are not a general mandate to install dependencies.

| Capability               | Existing/platform option                                                                                   | Selected reuse and constraints                                                                                                                                                                                                                                                                                |
| ------------------------ | ---------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Explorer interactions    | Existing onboarding has no tree; custom recursion would leave keyboard, focus and drag/drop behavior to us | [React Arborist](https://github.com/brimdata/react-arborist) 4.0.1, MIT, React >=18 plus React DnD16 peers. App still owns filesystem authorization, collision/cycle checks, revisions and durable moves.                                                                                                     |
| Source editor            | Existing source screenshot used a narrow textarea; no reusable editor was installed                        | [Monaco React](https://github.com/suren-atoyan/monaco-react) 4.7.0 explicitly supports React19, plus [Monaco Editor](https://github.com/microsoft/monaco-editor) 0.57.0, MIT. Bundle ESM assets/workers locally under Tauri CSP. C# syntax coloring is available; full semantic IntelliSense is not asserted. |
| Resizable panes          | Browser CSS cannot supply accessible keyboard-operated splitters by itself                                 | Official [shadcn Resizable](https://ui.shadcn.com/docs/components/resizable) backed by react-resizable-panels4.14.8 (React18/19), using its installed v4 API. Avoid a custom pointer/resize implementation.                                                                                                   |
| Controls/forms/dialogs   | Existing checked-in shadcn Button/Dialog/Tooltip and semantic design tokens                                | Generate additional primitives from the same official registry; use public size/variant APIs without per-screen geometry overrides.                                                                                                                                                                           |
| Native project picker    | No native folder picker in the onboarding bridge                                                           | Official [Tauri Dialog](https://tauri.app/plugin/dialog/) plugin2.8.3, initialized with scoped desktop permissions. Cancellation does not change project.                                                                                                                                                     |
| Settings and safe writes | Existing validated Preferences store, tempfile and typed IPC already handle onboarding                     | Preserve that store. Workspace state uses focused validated session metadata and the same atomic-write approach; adding a parallel general settings framework would not remove the domain validation/conflict requirements.                                                                                   |
| Compilation/schema       | Preserved engine Run.csproj already exposes StrategySource/StrategyHelperSources and StrategyMetadata      | Reuse the .NET SDK compiler, original source-linked runner and reflection metadata. Never implement a C# parser, infer successful builds from syntax coloring or mutate numerical engine sources. Missing SDK/cancellation/compile errors are explicit.                                                       |

Charts are an example motivating the skill, not part of this Build milestone; no chart library or fabricated market data is added. Versions/licenses and peer compatibility were checked from package metadata before installation. Actual integrations still require runtime, accessibility, offline and filesystem QA.

Native visual QA found horizontal clipping when a saved preset's long name exceeded its flex row's intrinsic minimum. The preset rows use a bounded `minmax(0, 1fr) auto` grid. This small form uses ordinary themed CSS vertical overflow rather than a table-sized Radix Scroll Area wrapper; its Input, Select, Label and Button primitives remain official shadcn components. The native test asserts no horizontal overflow or scroll offset after saving a preset. No custom scroll framework or component-geometry override is needed.

Platform research also found a required integration detail: [Tauri's Windows configuration](https://v2.tauri.app/reference/config/#windowconfig) requires `dragDropEnabled: false` for frontend HTML5 drag/drop, otherwise WebView2's native handler replaces it. Use that setting for Arborist; the custom caption's native window dragging remains separate. This milestone uses the native folder dialog rather than OS file-drop import.
