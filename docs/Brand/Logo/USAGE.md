# Dotatel logo usage

## Preferred files

- Light surface: `SVG/dotatel-logo-primary.svg`
- Forest/dark surface: `SVG/dotatel-logo-dark.svg` (transparent)
- One-color light print: `SVG/dotatel-logo-black.svg`
- One-color dark print: `SVG/dotatel-logo-white.svg`
- Avatar/favicon: the corresponding `dotatel-mark-*` file

## Clearspace

Keep clearspace on every side equal to the height of the wordmark's horizontal stroke. More space is encouraged.

## Minimum size

- Horizontal logo: 120 px digital, 32 mm print
- Stand-alone mark: 20 px digital, 6 mm print

Below the minimum size, use the mark rather than the full logo.

## Backgrounds

Use only Paper, white, Forest, Ink, or calm photography with sufficient contrast. Do not place the logo over busy charts. Production SVGs are transparent. Files named `*-on-forest.svg` include a Forest background for dependable previewing only.

## Prohibited changes

Do not alter colors, change the diagonal split, recolor individual letters, add effects, compress, rotate, place in a container, or attach the slogan to the artwork.
